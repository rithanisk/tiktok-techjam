# Upstream participant kit

This standalone repository was built from the public TikTok TechJam 2026 Track 4 participant kit:

- Repository: https://github.com/TechJam2026/techjam-conversational-search
- Base commit available in the supplied checkout: `3407835` (`Clarify TechnicalScore judging role`)
- Participant-kit release: https://github.com/TechJam2026/techjam-conversational-search/releases/tag/participant-kit

The organizer-provided evaluator, API contract, public development sessions, competition specification, submission rules, baseline results, and data-attribution document were retained. The final standalone snapshot intentionally does not depend on the upstream Git history, so it can be cloned from a Git bundle without network access.
